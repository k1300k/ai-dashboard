## 설치 및 실행

### 옵션 A: Docker Compose (가장 쉬운 방법) ⭐

#### 1. 저장소 클론
```bash
git clone https://github.com/k1300k/ai-dashboard.git
cd ai-dashboard
```

#### 2. OpenAI API 키 설정
```bash
# backend/.env 파일 생성
cp backend/.env.example backend/.env

# 편집기로 backend/.env 열기
nano backend/.env  # 또는 vim, code 등

# 다음 줄을 찾아서 실제 API 키로 변경:
OPENAI_API_KEY=sk-your-actual-openai-api-key-here
```

**OpenAI API 키 발급 방법:**
1. https://platform.openai.com 방문
2. 로그인 또는 회원가입
3. API Keys 메뉴 클릭
4. "Create new secret key" 클릭
5. 생성된 키를 복사하여 .env 파일에 붙여넣기

#### 3. Docker Compose로 실행
```bash
docker-compose up -d
```

#### 4. 데이터베이스 초기화
```bash
docker-compose exec backend alembic upgrade head
```

#### 5. 접속
- **프론트엔드**: http://localhost:3000
- **백엔드 API**: http://localhost:8000
- **API 문서**: http://localhost:8000/docs

### 옵션 B: 로컬 환경 (개발자용)

#### 백엔드 설정

```bash
cd backend

# 가상환경 생성
python3 -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 의존성 설치
pip install -r requirements.txt

# PostgreSQL 데이터베이스 생성
psql -U postgres
CREATE DATABASE thinkgraph;
CREATE USER thinkgraph WITH PASSWORD 'thinkgraph_password';
GRANT ALL PRIVILEGES ON DATABASE thinkgraph TO thinkgraph;
\q

# Redis 시작
redis-server &

# 환경변수 설정
cp .env.example .env
nano .env  # OPENAI_API_KEY 설정

# 데이터베이스 마이그레이션
alembic upgrade head

# 서버 실행
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

#### 프론트엔드 설정 (새 터미널)

```bash
cd frontend

# 의존성 설치
npm install

# 개발 서버 실행
npm run dev
```

접속: http://localhost:3000

## AI 기능 사용하기

### ✨ AI 아이디어 확장

**목적**: 하나의 아이디어에서 관련된 5개의 새로운 아이디어를 AI가 자동 생성

#### 사용법:
1. 확장하고 싶은 노드 선택
2. 노드 위의 ✨ (별) 버튼 클릭
3. 잠시 대기 (AI 처리 중)
4. 5개의 새 노드가 자동으로 생성됨

#### 예시:

**입력 노드**: "건강 관리 앱"

**AI 생성 결과**:
```
┌──────────────────┐
│  건강 관리 앱    │
└────────┬─────────┘
         │
    ┌────┴────┬────────┬────────┬────────┐
    │         │        │        │        │
┌───▼──┐  ┌──▼──┐ ┌──▼──┐ ┌──▼──┐ ┌──▼──┐
│운동  │  │식단 │ │수면 │ │스트 │ │건강 │
│추천  │  │관리 │ │분석 │ │레스 │ │리포 │
│AI    │  │     │ │     │ │관리 │ │트   │
└──────┘  └─────┘ └─────┘ └─────┘ └─────┘
```

#### 생성되는 아이디어 유형:
- **확장 (Extends)**: 기존 아이디어를 발전시킨 것
- **대안 (Alternative)**: 다른 접근 방법
- **전제조건 (Prerequisite)**: 필요한 선행 작업
- **응용 (Application)**: 실제 적용 사례

### 📊 AI 아이디어 평가

**목적**: 아이디어의 실현가능성과 임팩트를 AI가 분석하여 점수 부여

#### 사용법:
1. 평가하고 싶은 노드 선택
2. 노드 위의 📊 (차트) 버튼 클릭
3. AI가 분석 완료 (약 3-5초)
4. 노드에 점수 배지 표시됨

#### 평가 기준:

**Impact Score (임팩트 점수, 1-10)**
- 시장 크기
- 혁신성
- 사회적 가치
- 경쟁력

**Feasibility Score (실현가능성 점수, 1-10)**
- 기술적 난이도
- 필요한 리소스
- 예상 개발 시간
- 팀 역량

**Priority Score (우선순위 점수, 1-10)**
- Impact × 0.6 + Feasibility × 0.4
- 어떤 아이디어부터 시작할지 추천

#### 예시:

```
┌──────────────────────────┐
│  AI 기반 운동 추천       │
│                          │
│  사용자 데이터 분석하여  │
│  맞춤형 운동 제공        │
│                          │
│  📊 AI 평가 점수:        │
│  ├ 임팩트: 8.5/10       │
│  ├ 실현가능성: 6.0/10   │
│  └ 우선순위: 7.5/10     │
│                          │
│  💡 추천사항:            │
│  - MVP 빠른 출시 권장    │
│  - 파트너십 고려         │
└──────────────────────────┘
```

#### 점수별 해석:

**우선순위 8-10**: 🟢 즉시 실행 권장
- 임팩트 높고 실현 가능
- 최우선 과제로 추진

**우선순위 5-7**: 🟡 계획 단계에서 고려
- 중장기 과제로 준비
- 리소스 확보 후 진행

**우선순위 1-4**: 🔴 보류 또는 재검토
- 임팩트 낮거나 실현 어려움
- 조건 변화 시 재평가

#### 사용법:
1. 상단 "AI 요약" 버튼 클릭
2. AI가 전체 노드 분석 (약 5-10초)
3. 요약 팝업 표시

#### 요약 내용:

**1. 주요 테마 파악**
- 가장 많이 다룬 주제
- 반복되는 패턴

**2. 최우선 아이디어**
- 점수 기반 Top 3
- 추천 이유

**3. 다음 단계 제안**
- 추가 탐색이 필요한 영역
- 누락된 관점

**4. 잠재적 기회**
- 연결 가능한 아이디어
- 시너지 효과

## 문제 해결

### Q1: AI 기능이 작동하지 않습니다

**증상**: ✨ 버튼 클릭 시 에러 메시지

**해결방법**:
```bash
# 1. OpenAI API 키 확인
cat backend/.env | grep OPENAI_API_KEY

# 2. API 키가 없거나 잘못되었다면:
nano backend/.env
# OPENAI_API_KEY=sk-실제-키-입력

# 3. 백엔드 재시작
# Docker 사용 시:
docker-compose restart backend

# 로컬 환경:
# Ctrl+C로 중지 후
uvicorn app.main:app --reload
```

### Q2: 노드가 저장되지 않습니다

**증상**: 새로고침 시 노드 사라짐

**해결방법**:
```bash
# 1. 데이터베이스 연결 확인
docker-compose ps  # postgres 상태 확인

# 2. 마이그레이션 실행
docker-compose exec backend alembic upgrade head

# 3. 브라우저 콘솔 확인 (F12)
# Network 탭에서 API 요청 상태 확인
```

### Q3: 프론트엔드가 로딩되지 않습니다
